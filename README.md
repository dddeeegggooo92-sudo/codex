# Mandarin Express Landing

Landing page estatica para un curso online de chino mandarin.

## Archivos

- `index.html`: pagina completa con HTML, CSS y JavaScript en un solo archivo.

## Deploy en Cloudflare Pages

1. Sube este proyecto a un repositorio de GitHub.
2. En Cloudflare, entra a `Workers & Pages`.
3. Crea una app de `Pages` y conecta el repositorio.
4. Usa estos valores:
   - Framework preset: `None`
   - Build command: vacio
   - Build output directory: `/`
5. Publica el deploy.
